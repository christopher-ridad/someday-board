# Someday Board

A scrapbook wall for the things you keep putting off. Pin things up, pull one off the board each week/month, and turn it into a photo memory once it's done.

**The app lives in [`mobile/`](mobile/)** — a native Expo/React Native app backed by Supabase, built for testing on a real iPhone via Expo Go without needing a Mac. See [`mobile/README.md`](mobile/README.md) for setup.

(An earlier version of this project was a vanilla HTML/CSS/JS PWA with no backend. It's been fully replaced by the native app above; its history is still in git if you ever want to look back at it.)
